## prerequisite computation and download:

```
sbatch scripts/generalized_processing/static_script.sbatch
```

## internal data preprocessing and feature extraction:

```
sbatch --array=1-689%20   scripts/generalized_processing/compute_features_mapq.sbatch   30 false ./data/manifest/internal_metadata_ly.csv ./data/internal_features_ly
```

## submitting internal data matrix building: 

### for light features (no fsr)
```
sbatch --array=0-12 --mem=24G scripts/generalized_processing/matrix_build_array.sbatch   30   data/internal_features_ly   data/matrix_internal_ly   data/manifest/internal_metadata_ly.csv
```

### for heavy features (fsr)
```
 sbatch --array=13-13 --mem=32G scripts/generalized_processing/matrix_build_array.sbatch 30 data/internal_features_ly data/matrix_internal_ly data/manifest/internal_metadata_ly.csv
```
