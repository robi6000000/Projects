## Submission Commands — `gen_svm.sbatch`

Single unified script: `scripts/generalized_modelling/gen_svm.sbatch`

Feature index reference:
- **light** (0–6, 8G): `length edm iedm eedm eoedm cposedm fsd`
- **med** (7–12, 24G): `pfe coverage ends ocf ifs wps`
- **heavy** (13, 64G): `fsr`

Positional args: `<option> <matrix_folder> <kernel> <gc> <pca> <pca_components> <cv_repeats> <mapq> [run_tag]`

```bash
# light — small matrices, 8G
sbatch --job-name=cv_light --mem=8G  --array=0-6%5   scripts/generalized_modelling/gen_svm.sbatch cv_old data/matrix linear false true 150 1 30

# med — ~560K-feature matrices, 24G
sbatch --job-name=cv_med   --mem=24G --array=7-12%3  scripts/generalized_modelling/gen_svm.sbatch cv_old data/matrix linear true  true 150 1 30

# heavy — fsr, 64G
sbatch --job-name=cv_heavy --mem=64G --array=13-13   scripts/generalized_modelling/gen_svm.sbatch cv_old data/matrix linear false true 150 1 30
```

Note: GC correction (`gc=true`) only applies to med features (pfe, coverage, ends, ocf, ifs, wps); it is automatically disabled for all others by `gen_svm_feature.py`.
