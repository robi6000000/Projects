# 2026-05-09

## Codebase refactoring

### gen_cfdna_model.py — removed cv/cv_old dichotomy
Removed the uncalibrated (probability=False + sigmoid) code path entirely. Only calibrated Platt-scaling (probability=True) remains.
- cv_svm_old() renamed to cv_svm(), _build_estimator_old() renamed to _build_estimator()
- sigmoid cv_svm() and probability=False _build_estimator() removed
- fit_svm() merged directly into train_model()
- predict() always uses predict_proba, no sigmoid fallback
- unused imports cleaned

### gen_svm_feature.py — removed test and cv_old options
- test option removed (handled by gen_svm_test.py)
- cv_old removed as valid option
- only run_tag is optional (arg 12), all other args required
- CV output filename: {config}_{feature}_cv_probs.csv -> {feature}_cv_probs.csv

### gen_svm.sbatch
Updated $1 OPTION comment from (cv, cv_old, train, test) to (cv, train).

### gen_svm_test.py — new inference script
Standalone script for running predictions on a test set using a saved .pkl. Loads pkl, aligns feature columns, calls CFDNAModel.predict(). All preprocessing state is in the pkl, no config args needed.
```
python scripts/generalized_modelling/gen_svm_test.py [test_matrix_path] [model_path] [output_probs_path]
```

### gen_svm_test.sbatch — redesigned as SLURM array
Now mirrors gen_svm.sbatch structure. $3 changed from DATASET_TAG (appended to filename) to DATASET_DIR (subfolder under test/). Output: $MODEL_CONFIG_DIR/test/${DATASET_DIR}/${FEATURE}_probs.csv.
```
sbatch --array=0-6 --mem=8G scripts/generalized_modelling/gen_svm_test.sbatch [TEST_MATRIX_FOLDER] [MODEL_CONFIG_DIR] [DATASET_DIR] [MAPQ_FILTER]
```

### gen_evaluate.py — unified evaluation script
Computes AUC for all .csv files in a directory (CV probs or test predictions). Feature name parsed as first _-delimited token of filename. Output columns: feature, auc, zhou_auc (zhou_auc to be removed before final thesis figures).
```
python scripts/generalized_modelling/gen_evaluate.py [directory] [output_csv]
```
Examples:
```bash
python scripts/generalized_modelling/gen_evaluate.py data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/cv data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/results_cv.csv
python scripts/generalized_modelling/gen_evaluate.py data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/test/prevelynch_test data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/feature_results_test/results_ly.csv
python scripts/generalized_modelling/gen_evaluate.py data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/test/genoscan data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/feature_results_test/results_gs.csv
```

## Domain shift finding — motif features
Testing Cristiano-trained models on LY test set: motif features (edm, iedm, eedm, eoedm, cposedm) predict ~1.0 for all LY samples. Diagnostic: scaled feature mean = 1.67 (expected ~0), confirming systematic distribution shift. Length generalises well (AUC 0.768). Med features TBD — GC correction may reduce offset.

Note: AUC < 0.5 for some features does not imply the inverted prediction is useful. Should not flip AUC post-hoc without a pre-specified mechanistic reason.
