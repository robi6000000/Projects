# 2026-05-09

## Codebase refactoring

### gen_cfdna_model.py — removed cv/cv_old dichotomy
Removed the uncalibrated (`probability=False` + sigmoid) code path entirely. Only calibrated Platt-scaling (`probability=True`) remains.
- `cv_svm_old()` → renamed to `cv_svm()` (the only CV method now)
- `_build_estimator_old()` → renamed to `_build_estimator()`
- `cv_svm()` (sigmoid variant), `_build_estimator()` (probability=False variant) removed
- `fit_svm()` merged into `train_model()` directly
- `predict()` sigmoid fallback removed — always uses `predict_proba`
- Unused imports cleaned (`sys`, `os`, `pickle`, `StratifiedShuffleSplit`, `StratifiedKFold`, `cross_val_score`, `roc_auc_score`)

### gen_svm_feature.py — removed test and cv_old options
- `test` option removed — handled by `gen_svm_test.py`
- `cv_old` no longer a valid option (routes to same `cv_svm()` as `cv`)
- Optional args simplified: only `run_tag` is optional (arg 12), all other args are required
- CV output filename changed from `{config}_{feature}_cv_probs.csv` → `{feature}_cv_probs.csv`

### gen_svm.sbatch — comment updated
Updated `$1 OPTION` comment from `(cv, cv_old, train, test)` to `(cv, train)`.

### gen_svm_test.py — new inference script
Standalone script for running predictions on a test dataset using a saved model `.pkl`.
```
Usage: python scripts/generalized_modelling/gen_svm_test.py \
  [test_matrix_path] [model_path] [output_probs_path]
```
Handles feature column alignment from the saved model dict. No config args needed — all preprocessing state is in the `.pkl`.

### gen_svm_test.sbatch — updated to SLURM array with dataset subdirectory
Redesigned to mirror `gen_svm.sbatch` with SLURM array indexing. `$3` changed from `DATASET_TAG` (appended to filename) to `DATASET_DIR` (creates subfolder under `test/`).
Output: `$MODEL_CONFIG_DIR/test/${DATASET_DIR}/${FEATURE}_probs.csv`
```
Usage: sbatch --array=0-6 --mem=8G scripts/generalized_modelling/gen_svm_test.sbatch \
  [TEST_MATRIX_FOLDER] [MODEL_CONFIG_DIR] [DATASET_DIR] [MAPQ_FILTER]
```

### gen_evaluate.py — unified evaluation script
Computes AUC for all `.csv` files in a given directory (CV probs or test/train predictions) and saves a results table. Feature name is parsed as the first `_`-delimited token of the filename.
```
Usage: python scripts/generalized_modelling/gen_evaluate.py [directory] [output_csv]
```
Output columns: `feature`, `auc`, `zhou_auc` (Zhou et al. 2022 reference, to be removed before final thesis figures).

Example — evaluate Cristiano 10x10 CV:
```bash
python scripts/generalized_modelling/gen_evaluate.py \
  data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/cv \
  data/matrix/svm_by_feature/svm_linear_pca150.0_gc_mapq30/results_cv.csv
```

Example — evaluate LY train 10x10 CV:
```bash
python scripts/generalized_modelling/gen_evaluate.py \
  data/matrix_internal_ly_train/svm_by_feature/svm_linear_pca150.0_gc_mapq30/cv \
  data/matrix_internal_ly_train/svm_by_feature/svm_linear_pca150.0_gc_mapq30/results_cv.csv
```

## CRC-specific external validation

### Motivation
Zhou et al. (2022) perform cancer-type-matched external validation: train on cancer type X from dataset A, validate on cancer type X from dataset B. Testing Cristiano multi-cancer models on PreveLynch (CRC) and GeoScan (prostate) conflates cancer-type mismatch with cohort effects. To properly validate on PreveLynch, the Cristiano training set should be restricted to CRC + healthy.

### CRC ensemble pipeline (pending all CV probs)
Once 10×10 CV is complete for all features:
1. **Build meta-matrix** — combine per-feature OOF CV probabilities into a single matrix (one column per feature) using `meta_matrix_build.py`. Input: `cv/` probs directory. Output: `meta_matrix.csv`.
2. **Ensemble 10×10 CV** — run cross-validated ensemble model on the meta-matrix to get unbiased ensemble OOF probabilities.
3. **Train ensemble** — fit final ensemble model on the full meta-matrix.
4. **Test set meta-matrix** — combine per-feature test predictions (from `test/prevelynch_test/` and `test/genoscan/`) into test meta-matrices.
5. **Ensemble test predictions** — run trained ensemble on test meta-matrices to get final predicted probabilities.
6. **Evaluate** — run `gen_evaluate.py` on ensemble CV probs and test probs.

## Domain shift finding — motif features
Testing Cristiano-trained models on LY test set revealed that motif features (edm, iedm, eedm, eoedm, cposedm) predict ~1.0 for all LY samples (healthy and cancer alike). Diagnostic showed scaled feature mean = 1.67 (should be ~0), indicating systematic distribution shift between cohorts. Length feature generalises well (AUC 0.768). Med features (pfe, coverage etc.) TBD — GC correction may reduce offset.
