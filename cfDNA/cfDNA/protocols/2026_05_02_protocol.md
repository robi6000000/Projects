## PreveLynch Feature Computation and Matrix building
Selected only features which were the last sample of a patient, filtering down from 689 to 581 samples.

metadata file: `data/manifest/internal_metadata_ly_filtered.csv`
train metadata file: `data/manifest/internal_metadata_ly_filtered_train.csv`
test metadata file: `data/manifest/internal_metadata_ly_filtered_test.csv`
train (80%): 465 samples (381 control, 84 cancer)
test (20%): 116 samples (92 control, 24 cancer)

feature computation was submitted using:
```
sbatch --array=0-580 scripts/generalized_processing/compute_features_mapq.sbatch 30 true data/manifest/internal_metadata_ly_filtered.csv data/internal_features_ly
```

matrix building was submitted using:
```
sbatch --job-name=build_light --array=0-6 --mem=8G scripts/generalized_processing/matrix_build_array.sbatch 30 ./data/internal_features_ly ./data/matrix_internal_ly/by_feature ./data/manifest/internal_metadata_ly_filtered.csv
```
```
sbatch --job-name=build_med --array=7-12 --mem=24G scripts/generalized_processing/matrix_build_array.sbatch 30 ./data/internal_features_ly ./data/matrix_internal_ly/by_feature ./data/manifest/internal_metadata_ly_filtered.csv
```
```
sbatch --job-name=build_heavy --array=13-13 --mem=64G scripts/generalized_processing/matrix_build_array.sbatch 30 ./data/internal_features_ly ./data/matrix_internal_ly/by_feature ./data/manifest/internal_metadata_ly_filtered.csv
```
Same was done for train and test subsets, with `internal_metadata_ly_filtered_train.csv` and `internal_metadata_ly_filtered_test.csv` respectively.
