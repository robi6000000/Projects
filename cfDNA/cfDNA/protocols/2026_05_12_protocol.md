## Batch effects observation

Cross-dataset ROC (Cristiano → PreveLynch) shows a clear split:
- **Well-generalising features**: wps (0.943), coverage (0.910), ends (0.899), pfe (0.896), ifs (0.840), ocf (0.813) — all per-region features
- **Poor-generalising features**: edm (0.624), iedm (0.668), fsd (0.247), eedm (0.409), eoedm (0.500), ocedm (0.226) — all motif/FSD features

Root cause: end-motif and fragment-size features are sensitive to library preparation batch effects (enzymatic fragmentation bias, size selection). Per-region features (WPS, coverage, ends) measure biologically stable nucleosome/TF binding signal at fixed genomic loci, which is robust across cohorts.

Thesis implication: generalisation of novel motif features (iedm, eedm, eoedm, ocedm) requires either multi-cohort training or batch correction.
